Запознаване със среда за програмиране CodeBlocks

Първи стъпки в програмирането

Що е програмиране?

  • Програмите, които компютърът изпълнява, са последователности от инструкции
  • Програмистите пишат своите програми на езици за програмиране, които са разбираеми за тях
  • Програма, написана на език за програмиране, наричаме изходна програма
Състезателна информатика
  • Наука
  • Спорт
  • Изкуство
  • Професия

Средата за програмиране CodeBlocks

Инсталационен файл на средата за програмиране CodeBlocks ще бъде качен в Google Classroom на групата.
Можете да го изтеглите безплатно и от официалния сайт: https://www.codeblocks.org/

Създаване на нов файл с разширение .cpp

  1. File → New → File…
  2. Изберете бутон Go… и след това Next
  3. После изберете C++ и потвърдете с Next
  4. Чрез бутона “…” задаваме път до папката за съхранение и име на файла.
  5. След това потвърждаваме с бутона Finish.

Компилиране и изпълнение на програми

  • Build → Run (Ctrl + F10)
  • Build → Build and run (F9)

Файлове, създавани от средата

  • Файлове с разширение CPP: Съдържат текстовете на изходните програми и се получават след изпълнението на командата File → Save или чрез натискане на клавиша Ctrl + S.
  • Файлове с разширение EXE: Съдържат изпълними програми, еквивалентни на написаните. Създават се при компилиране на програма.

Работа с компютър

Задача: Извеждане на текст на екрана

  • В папка e_cpp_name съдайте програма с име p1.cpp.
  • Въведете в средата за програмиране CodeBlocks следния код на програмата
  • Компилирайте програмата с натискане на клавиш F9

Най-чести грешки

  • Пропуснат ред от вида #include <iostream>: Съобщение error: ‘cout’ was not declared…
  • Пропусната фигурна скоба }: Съобщение expected ‘}’
  • Неправилно написани или нещо липсващо в програмата (изтървана кръгла скоба и др.): Една или повече синтактични грешки, отбелязани в червено
  • Изтърван символ ; (с него завършва всеки оператор в езика C++): Съобщение expected ‘;’ before…
