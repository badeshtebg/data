Условен оператор[cite: 12]

Новото за вас от езика C++: Оператори за сравнение[cite: 12]

знак[cite: 12] действие[cite: 12]
<[cite: 12] по-малко[cite: 12]
<=[cite: 12] по-малко или равно[cite: 12]
>[cite: 12] по-голямо[cite: 12]
>=[cite: 12] по-голямо или равно[cite: 12]
==[cite: 12] равно (съвпада)[cite: 12]
!=[cite: 12] различно[cite: 12]

Резултат от операцията сравнение[cite: 12]

Резултатът от сравнението a < b е 1, ако е вярно, както например, ако сравним 3 и 5.[cite: 12]

Резултатът от сравнението a < b е 0, ако не е вярно, както например, ако сравним 5 и 5.[cite: 12]

С оператор cout << (a < b); можете да направите проверка.[cite: 12]

Разклоняване на пресмятанията[cite: 12]

Пример за намиране на по-голямото (максимума) от две числа:[cite: 12]

#include <iostream> using namespace std; int main() { int a, b, max; cin >> a >> b; if (a > b) max = a; else max = b; cout << max << endl; }[cite: 12]

Пример за намиране на максимума и на минимума на две цели числа[cite: 12]

#include <iostream> using namespace std; int main() { int a, b, max, min; cin >> a >> b; if (a > b) { max = a; min = b; } else { max = b; min = a; } cout << "max: " << max << ", " << "min: " << min << endl; }[cite: 12]

Условен оператор if (1)[cite: 12]

Форми на оператор if[cite: 12] Пример[cite: 12] Изпълнение[cite: 12] 
if(условие) оператор1;
else оператор2;
[cite: 12]		 
int a;
cin >> a;
if(a < 6) cout << "ok";
else cout << "no";
[cite: 12]		 При a = 6 ще се изведе “no”, т.к. условието (a < 6) не е изпълнено и се изпълнява оператора след else.[cite: 12] 
if(условие) оператор;
[cite: 12]		 
int a;
cin >> a;
if(a == 7) cout << "excellent";
[cite: 12]		 Съобщението "excellent" ще се изведе само, ако a е 7.[cite: 12]

Условен оператор if (2)[cite: 12]

Форми на оператор if[cite: 12] Пример[cite: 12] Изпълнение[cite: 12] 
if(условие)
{
    оператор1;
    оператор2;
}
else
{
    оператор3;
    оператор4;
}
[cite: 12]		 
int a, b, m, n;
cin >> a >> b;
if(b != 0)
{
    m = a / b;
    n = a % b;
}
else
{
    cout << "Division error";
    m = a;
}
[cite: 12]

Ако b не е 0 ще се извършат двете деления.[cite: 12]

Ако b е равно на 0 ще се изпълнят командите след else – ще се изведе съобщението и в m ще се запише стойността на a.[cite: 12]

Най-често срещани грешки[cite: 12]

Типични грешки[cite: 12] Съобщения от компилатора[cite: 12]
Не е описана променливата a
(забравен е ред int a;)[cite: 12]		 ‘a’ was not declared in this scope[cite: 12] 
if(a = 5) cout << "a е 5";

Бъркаме равно ли е с присвояване!
Така записано в условието не проверяваме дали a е 5, а казваме на a да стане 5.[cite: 12]		 Няма да изведе грешка.[cite: 12] 
#include <iostream>
using namespace std;
int main()
{
    int a;
    cout << "a = ";
    cin >> a;
    if(a > 5) cout << ">5" << endl;
    cout << "<=5";
}
[cite: 12]

Няма да изведе грешка.[cite: 12]

Искали сме да изведем съобщение „>5“, ако a > 5, и „<=5“ в противен случай, но сме изтървали else.[cite: 12]

Резултатът е, че ще видим на екрана и двете съобщения, ако a > 5.[cite: 12]

Размяна на стойностите на две променливи[cite: 12]

Понякога е трудно да се възприеме, че последователността
a = b; b = a;
няма да осъществи размяната![cite: 12]
Правилният подход е с въвеждане на допълнителна променлива:
int t = a, a = b, b = t;[cite: 12]

Размяна на стойностите на две променливи чрез функция от STL[cite: 12]
